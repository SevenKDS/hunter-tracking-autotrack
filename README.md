# Hunter Tracking (HT) v3.4

Аддон для охотников: автоматически переключает **выслеживание** под тип текущей цели
и даёт быстрый доступ к трекингу с иконки у миникарты.

Разработан под клиент **World of Warcraft Forever** (интерфейс 16001).

---

## Возможности

| Функция             | Описание                                                                |
| ------------------- | ----------------------------------------------------------------------- |
| Авто-трекинг        | При выборе цели включается нужное «Выслеживание»                        |
| Нейтральные мобы    | Жёлтые (атакуемые) мобы отслеживаются как обычные                       |
| Без повторов        | На однотипных мобах каст не повторяется                                 |
| Пропуск союзников   | Дружественные НПС, игроки и питомцы не трогаются                        |
| Пропуск трупов      | Мёртвые цели и трупы ничего не сбрасывают                               |
| Иконка у миникарты  | ЛКМ — трекинг под цель, ПКМ — вкл/выкл авто, перетаскивание по кругу    |
| Сохранение настроек | Режим авто и позиция иконки не сбрасываются при `/reload` и перезаходе  |
| Типы целей          | Животное, гуманоид, нежить, демон, элементаль, дракон, великан, скрытый |

## Установка

1. Распакуй архив `HunterTracking.zip`.
2. Перемести папку `HunterTracking` в `World of Warcraft/Interface/AddOns/`.
 Должно получиться: `Interface/AddOns/HunterTracking/HunterTracking.toc`.
3. Запусти игру.
4. Включи авто-трекинг один раз: `/ht auto`.

> Если после распаковки путь выглядит как `Interface/AddOns/HunterTracking/HunterTracking/HunterTracking.toc` — папка вложена дважды, вытащи внутреннюю наружу.

## Команды

| Команда     | Что делает                                       |
| ----------- | ------------------------------------------------ |
| `/ht auto`  | Включить / выключить авто-трекинг (сохраняется)  |
| `/ht`       | Переключить трекинг под текущую цель вручную     |
| `/ht diag`  | Показать тип, реакцию и атакуемость текущей цели |
| `/ht about` | Информация об аддоне и авторе                    |
| `/трекинг`  | То же, что `/ht`                                 |

---

## Иконка у миникарты

- **ЛКМ** — переключить трекинг под цель.
- **ПКМ** — включить или выключить авто-режим.
- **Перетаскивание** — двигать иконку по кругу миникарты, позиция сохраняется.
- **Наведение** — подсказка с текущим состоянием.

## Технические замечания

Аддон использует `CastSpellByName` — на клиенте Forever функции
`CastTracking`, `GetTrackingInfo` и фрейм `TrackingFrame` отсутствуют,
поэтому переключение трекинга выполняется кастом по имени заклинания.

Если на сервере переименуют способности, достаточно поправить таблицу
`TRACK` в начале `HunterTracking.lua`.
